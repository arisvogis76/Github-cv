Project “Network Monitor”
Η ανάπτυξη ενός  custom Κέντρο Λειτουργίας Δικτύου. Δηλαδή ενός ζωντανού ψηφιακού πίνακα ελέγχου που παρακολουθεί την υγεία των συσκευών ενός δικτύου σε πραγματικό χρόνο. 
Network Operations Center (NOC- Κέντρο Λειτουργίας Δικτύου): Κεντρικό σημείο ελέγχου, παρακολούθησης και διαχείρισης των υποδομών δικτύου ενός οργανισμού.
Αποτελείται από τα 3 βασικά κομμάτια: 
1)Frontend - Live Dashboard:
 To Frontend αποτελεί το οπτικό τμήμα της εφαρμογής με το οποίο αλληλεπιδρά ο χρήστης. Έχει δημιουργηθεί ένα web User Interface (UI) με δυναμικές γραμματοσειρές, CSS animations και έξυπνα φίλτρα για να προβάλει μόνο την πιο πρόσφατη και καθαρή εικόνα του δικτύου.
2) Backend - Node.js 
Ένα πρόγραμμα που τρέχει στο παρασκήνιο. Χρησιμοποιήθηκε το πρωτόκολλο ICMP που σαρώνει με pings το υποδίκτυο (192.168.3.1-254) ανά 1 λεπτό. Διαβάζει latency, αναγνωρίζει hostnames μέσω DNS και αντλεί τις MAC των συσκευών μέσω του  πρωτοκόλλου ARP.
3) Database - MS SQL Server
Μία βάση δεδομένων που καταγράφει την κατάσταση της κάθε IP. Κρατάει ιστορικό και διαθέτει μηχανισμό εκκαθάρισης δεδομένων για αυτά που υπάρχουν για πάνω από 48 ώρες. 
Καινοτομίες -Πλεονεκτήματα: 
1) Υπάρχει μια τμηματική σάρωση του δικτύου σε ομάδες των 25 ip. Με αυτό τον τρόπο το πρόγραμμα δεν "βομβαρδίζει" το δίκτυο και ο όγκος δεδομένων που διακινείται είναι απειροελάχιστος και δεν προκαλείται συμφόρηση.  
2) Το Dashboard επεξεργάζεται τα δεδομένα στην πλευρά του πελάτη (), εξαλείφοντας τις διπλοεγγραφές και δείχνοντας πάντα μόνο το τελευταίο status κάθε συσκευής, ταξινομημένο χρονολογικά ή ανά IP.
3) Τέλος, υπάρχει άμεση αναγνώριση προβλημάτων με χρωματική κωδικοποίηση.
4) Παρατηρείται ή  πτώση μιας κρίσιμης συσκευής τη στιγμή που συμβαίνει, πριν επηρεάσει τους χρήστες ή σε γρήγορο χρονικό διάστημα αφού αναγνωριστεί το πρόβλημα.
5) Τέλος, χάρη στην καταγραφή των MAC, υπάρχει ανά πάσα στιγμή πλήρη εικόνα για το ποιες και πόσες συσκευές είναι συνδεδεμένες. Οποιαδήποτε νέα, μη εξουσιοδοτημένη συσκευή ξεχωρίζει αμέσως.
